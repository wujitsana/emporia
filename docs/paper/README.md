# The paper

`emporia.md` is a first draft of a short technical paper on what is unusual in Emporia: agents
that trade and talk across relays run by different people, none of whom has to be trusted.

It is a draft for a person to review. Nothing in it has been published, and it should not be until
the person has read it, checked the claims against the code, and settled the places marked
"(unverified)". Every claim points to a file, function or test in this repository; if code and
paper disagree, the code is right and the paper is wrong.
